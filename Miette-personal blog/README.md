# Miette 个人博客

打开 dist/index.html 即可浏览，也可以在本目录运行 python -m http.server 8766 --directory dist 后访问 http://localhost:8766。

本版加入右侧音乐播放器：富士山下 / 陈奕迅。音频由用户提供的 FLAC 转为 192 kbps MP3，原文件保持不变。支持播放、暂停、进度跳转、音量、静音、单曲循环和收起。手机端显示底部紧凑播放器。

首次进入会尝试自动播放；浏览器阻止时点击播放按钮即可。手动暂停后会记住偏好，重新进入保持暂停。博文是标注过的示例，可在 dist/app.js 的 posts 数组中替换。
